# Selected product work

## Mindmap editor · Product build

**Problem.** When research is grouped into branches, reorganizing one theme can mean moving several connected notes. The editor needs to keep those relationships intact.

**What I built.** An interactive editor with branch moves, collapse, reparenting, and undo and redo. The persistence flow retains saved edits and collapsed branches when the board is reopened.

**Product decision.** Move a branch as a unit and make the operation reversible. Users can try a new structure and undo it without reconstructing the original branch.

**Verification.** A functional check confirmed that an edited board and its collapsed branch survived a page refresh. For usability, I would measure how long it takes to reorganize a sample board and count unintended moves.

## Affiliate management · B2B SaaS product work

**Problem.** Businesses running referral programs need to connect partner activity to revenue and see enough detail to investigate discrepancies.

**My role.** Built an affiliate management product from scratch within a CRM platform.

**Product lens.** Map the workflow from partner enrollment through attribution and reporting. Make each state explainable, especially when a user needs to trace a conversion back to a partner.

**How I would measure it.** Time to launch a program, share of programs with an active affiliate, and time to investigate an attribution discrepancy.
